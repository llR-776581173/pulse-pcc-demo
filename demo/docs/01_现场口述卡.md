# 01 · 现场口述卡（一线员工使用指引 · 内部归档 · 不上页面）

> **这份卡给谁**：门店店长、营销同事、客服与运营同事——每天打开这套工作台干活的一线人员。带新人、开周会、给同事演示时，照着念、照着点就行。
> **这份卡讲什么**：只讲「怎么用」，用大家平时说话的方式讲，让第一次上手的人也能一听就懂、照着就能做。
> **三条约定**：① 页面保持干净，屏幕上不出现任何「临时 / 未定 / 演示」字样；② 有几句分寸上的话，由带的人当面说清，不写在屏幕上；③ 谁改过标准、谁批准过发券，系统背后都留了记录，事后查得到（见 `02`）。

---

## 一、先花两分钟：这套工作台到底帮我们做什么

一句话：**把熟客照顾好，把优惠券花在刀刃上，把每一步为什么这么定讲清楚、记下来。**

- 以前我们凭印象判断「这位客人好像好久没来了」，现在系统把每位客人的来店节奏记成一段连续的故事，谁开始来得少、少到什么程度、后来有没有再回来，一眼看得见。
- 以前发券容易「谁安静了就都发一张」，其实很多客人歇一阵自己就会回来，白送一张等于白花钱。系统帮我们把有限的额度，优先留给最值得唤回、也最可能被唤回的人。
- 以前「为什么发、为什么没发」过几个月就说不清了。现在每一次发券、每一次改标准，都要有人点头、写一句理由，留个底，随时能查。

> 记住一个前提：**系统只给建议，拍板的永远是人**。它不会自己发券，也不会自己说谁「已经走了」。

## 二、一个普通工作日：从开店到收工，怎么用（重点）

下面按你真会遇到的事来讲。每个场景都写清「什么时候用 / 打开哪里 / 会看到什么 / 你能做什么 / 一句话怎么说」。

### 场景 1 · 早上开店 / 周会：先看看今天整体情况
- **打开**：左边菜单第一项「营销总览」。
- **会看到**：最上面几张数字卡——在册多少会员、多少人在正常复购、多少人开始来得少、多少人已经不来了；还有一句很关键的「平均提前几天发现」，意思是系统不是等客人彻底不来了才提醒，平均能提早几天察觉（现在是平均 5 天多）。
- **还能看到**：一张圆圆的分布图，把客人从「刚进店还没买过 → 第一次买 → 常来 → 来得少 → 很久没来 → 已经不来」排成一圈，旁边两列小条，左边三个是状态不错的，右边三个是要留意的。
- **你能做什么**：心里有数，今天该重点看哪一群人；点一下某个状态，就只看这一群。
- **一句话**：「先看大盘，知道今天该把心思花在哪批客人身上。」

### 场景 2 · 有客人来得少了：找到他，看看他的来店故事
- **打开**：「流失预警客户池」。
- **会看到**：三组现成的例子——已经又回来了的、正在提醒要留意的、一直来得挺稳的。点开任意一位，下面会出现一条他自己的来店小日记：浅棕色是正常来买，灰蓝色是系统开始提醒「来得少了」，深棕色是后来又回来了。
- **你能做什么**：先只挑重点看（默认就是精简版），想看全就点「展开全部交易」；换一位客人会自动回到精简版。想更细地了解他，点「画像」跳到下一个场景。
- **一句话**：「不是拍脑袋说他不来了，是顺着他这段时间的来店记录看出来的。」

### 场景 3 · 想专门了解某一位客人：翻他的档案
- **打开**：「单客户全景画像」（也可以从上一页点「画像」直接进来）。
- **会看到**：他现在处在哪个阶段、多久没来了、平时消费大概什么水平、系统提前几天提醒的；还有一张建议卡，写清楚推荐给什么、大概面额多少、回来的可能性有多大。
- **你能做什么**：结合你对这位客人的了解，决定要不要采纳建议。
- **一句话**：「系统给的是参考，认不认这位客人、要不要多照顾一点，还是你最清楚。」

### 场景 4 · 决定发不发、发多少：把额度花在值得的人身上
- **打开**：「干预效果复盘」和总览里的预算卡。
- **会看到**：这期额度能覆盖多少人、实际发到多少人、还有多少人没覆盖到、大概花多少钱；不同面额的券以往效果对比。
- **要明白的一件事**：系统会把客人分成几种处理方式——值得重点唤回的、常规关怀的、**节奏正常不必额外花钱的**、资料太少先不下结论的、客人没同意联系的直接不能选。「不花钱」也是正经决定：本来就会自己回来的客人，不用再送一张，把额度留给真正需要唤回的人；这个决定带理由、可以申诉。
- **一句话**：「不是谁安静就都发一张，是把钱花在刀刃上。」

### 场景 5 · 发券之前：必须有人点头、写清理由
- **打开**：「营销审批记录」。
- **会看到**：谁批的、凭什么批、什么时候批、有没有真的发出去（现在「发送」那一列都是空的）。
- **要记住**：**登记了不等于发出去了**。系统现在只负责把「批准」这个决定记下来，真正把券送到客人手上，是后面另一个环节的事，而且要在发送那一刻再确认客人还愿意接收；客人一旦说不想收，所有渠道立刻停。
- **一句话**：「批准是批准，发送是发送，两件事；客人退订了就一律不打扰。」

### 场景 6 · 觉得「来得少」的标准不合适：可以调
- **打开**：「规则阈值配置」。
- **会看到**：十几条判断标准，按「什么时候提醒 / 多久算久 / 怎么算回来」分好组，每条旁边有个小问号，点开就是大白话解释。
- **你能做什么**：改完标准，**填上你的名字和一句为什么要改**，再点「应用」。所有页面上的数字会一起更新，还会弹出一个小对比，告诉你改之前、改之后分别多少人被提醒、额度够覆盖多少人。
- **一句话**：「标准定松一点还是紧一点，是业务说了算，改完全店数字跟着一起变，还会给你看改前改后。」

### 场景 7 · 周会 / 月底要汇报：一键出总结
- **打开**：「干预效果复盘」，点「AI 生成月报」。
- **会看到**：一份放大、好读的总结，按「大盘 / 重点客人 / 额度花在哪 / 回来情况 / 下步建议」分好段，可以整篇复制走直接用。
- **一句话**：「不用自己凑数字拼汇报，点一下就能拿去用。」

### 场景 8 · 有任何不懂的：直接问右下角的小帮手
- **打开**：页面右下角的「AI 助手」。
- **会看到**：几个常见问题的快捷按钮，也可以自己打字问，比如「这期额度够不够」「哪些客人最该先看」。
- **要明白**：它只照着工作台里现有的数字回答，**没有的会老实说「现在没有这项数据」，不会瞎编**。想让它更聪明，由负责的同事在「设置」里配置一次即可；没配置也能用，会自动换成内置的口径回答。
- **一句话**：「像身边有个熟悉报表的同事，问一句就答，不知道就直说不知道。」

### 场景 9 · 某个数字看不懂：查大白话解释
- **打开**：「数据口径与帮助」。
- **会看到**：每个指标怎么算、数据从哪来、统计到哪一天、那十几条标准分别什么意思，还有常见问题；四块内容各自能单独往下翻，不用整页拉到底。
- **一句话**：「拿不准哪个数怎么来的，来这里看一眼就明白。」

> 手机、平板上也能用：左边菜单会收起来，点左上角那个三道杠展开；很宽的表格可以左右滑着看。

## 三、讲解时要顺带说清的 10 句话（业务语言版）

> 页面保持干净，下面这些不写在屏幕上，由带的人当面说。编号与 `09` / `10` / `03` 等文档里引用的「口述卡第 N 条」一一对应，方便对照。

| # | 什么时候说 | 一句话（可直接念） | 被追问时补一句 |
|---|---|---|---|
| 1 | 开场 | 「今天这套系统里放的是一批练习用的模拟客人记录，方便大家先把流程走熟；屏幕上的数字不是真实业绩，也不是对以后的预测或试验结论。」 | 换成真实客人数据、标准按咱们实际口径定下来之后，用法一模一样。 |
| 2 | 讲判断标准时 | 「多久算『来得少』、提前几天提醒，这些标准现在是暂定的；等方案定下来，我们会按门店的真实情况重新校准，改设置就行，不用动系统。」 | 主要是四件事：消费间隔怎么分档、多久算真不来了、提前几天提醒、活跃人数按谁算。 |
| 3 | 讲到券和钱时 | 「券面额、大概多少人会用、毛利这些目前是估的，屏幕上的金额会跟着设置实时变。」 | 真金白银 = 面额 × 会用券的比例 × 毛利，三个数一动，金额就跟着动。 |
| 4 | 讲发券 / 回流时 | 「发券这一步现在只做登记，券还没真发出去；演示里看到的『客人又回来了』是他本来的消费记录，不是我们发券带来的结果。」 | 批准不等于发送；客人一旦说不想收，所有渠道立刻停；真正发送是后面另一个环节，且要在发送那一刻再确认一次。 |
| 5 | 讲建议名单时 | 「这个名单只是帮我们排个先后、先看谁，不代表这么发就一定赚多少；到底有没有效果，得做过对照才知道，目前还没做。」 | 现在没有任何「提升了多少」「回报多少」的结论可以报，也不该报。 |
| 6 | 讲门店提醒时 | 「哪家店最近老客人来得少，系统只提醒、不自动停发；要暂停得经理签字，签之前先看代价。」 | 试算下来，直接停发并不省钱，只是把券换给了价值更低的客人。 |
| 7 | 讲回头比例时 | 「不同时间段算出来的回头比例，我们从不放在一张表里比。」 | 因为统计的截止日不一样，混在一起会看错。 |
| 8 | 改完标准后 | 「刚才标准一改，整套数字都重新算过了，页面上每个数都出自同一套标准，不会互相打架。」 | 不会出现「这边说客人来得少、那边说他正常」的情况。 |
| 9 | 切换例子时 | 「这几位是从数据里真挑出来的客人，不是摆好的动画；标准一改，他们所处的阶段也会跟着变。」 | 想看完整的「变少 → 提醒 → 又回来」过程，点「展开全部交易」。 |
| 10 | 收尾 | 「今天展示的是『怎么把决定做清楚、把过程记下来』，不是『效果有多好』；没做过真实对照，也没有对照组结论。」 | 与 `09` 收尾口径一致。 |

## 四、带新人 / 演示前勾检

- [ ] 先讲第一节「这套东西帮我们干什么」，再按第二节九个场景走一遍（重点是「怎么用」）
- [ ] 全程用大白话讲，第一次上手的同事也能跟上
- [ ] 屏幕上确认没有任何「临时 / 未定 / 演示 / 数据没接好」这类字样
- [ ] 七个页面都能点开、左边菜单能收起 / 展开
- [ ] 场景 2 的三组例子都能切换，来店记录能展开、能收回
- [ ] 场景 6 改标准时填了名字和理由，改前改后对比能弹出来
- [ ] 审批抽查能答上「发给谁 / 凭什么 / 谁点头 / 什么时候 / 有没有真发出去」
- [ ] 第三节 10 句话过一遍，屏幕共享时不切到本文件

## 五、给带演示 / 培训的人（内部备注）

界面始终保持一套成熟商用系统的样子，不出现任何「还没做完、仅供演示」之类的字样。需要交代的分寸，全部由第三节当面说清；谁改过标准、谁批准过发券，系统背后也都留了底，具体见 `02_口径占位登记表.md`。这样暂定的标准就不会被谁不小心当成已经定死的结论。
