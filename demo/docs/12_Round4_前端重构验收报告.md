## 3. 改动设计（与样板明确区分）

### 3.1 布局框架
- **可折叠左侧导航 + 右侧主内容区**，告别单页长滚动。折叠按钮在侧栏顶部，展开 238px / 折叠 70px；
  ≤1000px 视口自动收为图标条。四个视图 DOM **常驻**、用 `.view.active` 显示切换，模块彼此隔离。
- 菜单为自有业务命名：**营销总览 / 客户案例演示 / 营销审批记录 / 规则阈值配置**（不使用样板菜单名）。
- 高亮用品牌暖棕 `--brush:#8A5A3C` + 白字，无红色高亮；侧边栏背景为**低饱和奶棕**
  `linear-gradient(#F1E4D3 → #EADCC8)`，非强对比深色侧栏。

### 3.2 组件范式
- 右侧响应式栅格卡片：`.g4 / .g21 / .g2 / .g3` + `.card`，统一 14px 圆角、
  `0 2px 12px rgba(58,46,45,.055)` 柔和浅阴影、18–20px 内边距。
- **每个视图顶部一条本模块专属筛选栏**（评估周期 / 日期范围 + 客户分组 / 决策分组 / 参数分组）。
  筛选状态存于 `VIEW_FILTERS[view]`，`applyViewFilters(v)` **只遍历当前 `.view[data-view=v]` 内的行**；
  `data-frow` 参与日期过滤、`data-fgroup` 参与分组过滤，不触发任何后端请求、不重置其它视图。
- 信息层级：视图顶部核心数字（KPI / mini 卡）→ 中部汇总图表 → 底部明细列表。
- 保留 PCC 官方 SVG logo（侧栏左上角）；页头右上与页脚各一枚低透明度花卉点缀
  （opacity .055–.07、`pointer-events:none`），不遮挡任何数据区。

### 3.3 图表独立设计（不照搬样板排版 / 条形图样式 / 标题文案）
| 区块 | 本轮独立设计 |

| 六出口漏斗 | 品牌色系圆角横条 + 左侧标签 / 右侧数字，颜色统一为五色系 + 灰阶（无大红大绿） |
